# XHTTP: Beyond REALITY

See the [XHTTP: Beyond REALITY discussion](https://github.com/XTLS/Xray-core/discussions/4113) for the transport description and configuration examples.

When a VLESS shared pool runs over XHTTP, the client logs a warning and continues startup. XHTTP reuses HTTP connections through XMUX. [Multiplex settings](../outbounds/vless.md#multiplex).

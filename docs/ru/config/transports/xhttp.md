# XHTTP: Beyond REALITY

Описание транспорта и примеры настройки см. в обсуждении [XHTTP: Beyond REALITY](https://github.com/XTLS/Xray-core/discussions/4113).

При включённом общем пуле [VLESS Multiplex](../outbounds/vless.md#multiplex) поверх XHTTP клиент выводит предупреждение и продолжает запуск. XHTTP управляет повторным использованием HTTP-соединений через XMUX.

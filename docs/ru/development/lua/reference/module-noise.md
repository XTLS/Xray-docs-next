# xray.finalmask.noise

Генерирует случайные данные, необходимые для генерации шума.

```lua
local noise = require("xray.finalmask.noise")
```

## Указатель API

| Категория | Член API                                           | Описание                                |
| --------- | -------------------------------------------------- | --------------------------------------- |
| Функция   | [`noise.Random(...)`](#noise-random)               | Генерация случайных байтов              |
| Функция   | [`noise.RandomBetween(...)`](#noise-randombetween) | Генерация случайного числа из диапазона |

Обе функции доступны во всех скриптах. Пакеты шума передаются через [`plan:Add`](./hook-noise.md#plan-add) в [Hook шума](./hook-noise.md).

## Функции

### noise.Random

```lua
local bytes = noise.Random(size)
```

Генерирует случайные байты заданной длины, которые можно напрямую использовать как содержимое пакета шума.

**Параметры**

| Параметр | Тип      | Описание / Требования                                                       |
| -------- | -------- | --------------------------------------------------------------------------- |
| `size`   | `number` | Обязателен; число байтов, должно быть целым числом в диапазоне `0 .. 65535` |

**Возвращаемые значения**

| Значение | Тип      | Описание                                                    |
| -------- | -------- | ----------------------------------------------------------- |
| `bytes`  | `string` | Байтовая строка такой длины, не равна `nil`; при `0` — `""` |

**Поведение**

Используется криптографически стойкий источник случайности, поэтому результат каждого вызова отличается. Возвращается байтовая строка, а не текст, и она может содержать любые байты.

Если параметр выходит за пределы диапазона или не является числом, возникает исключение Lua; этот экземпляр уничтожается, а шум в этот раз не отправляется.

### noise.RandomBetween

```lua
local value = noise.RandomBetween(from, to)
```

Генерирует случайное целое число из замкнутого интервала; его можно использовать для случайной длины или случайной задержки.

**Параметры**

| Параметр | Тип      | Описание / Требования                                                   |
| -------- | -------- | ----------------------------------------------------------------------- |
| `from`   | `number` | Обязателен; нижняя граница, должна удовлетворять `0 <= from`            |
| `to`     | `number` | Обязателен; верхняя граница, должна удовлетворять `from <= to <= 65535` |

**Возвращаемые значения**

| Значение | Тип      | Описание                                                             |
| -------- | -------- | -------------------------------------------------------------------- |
| `value`  | `number` | Целое число между `from` и `to`, включая обе границы, не равно `nil` |

**Поведение**

Используется тот же источник случайности, что и в `noise.Random`, и оба граничных значения могут встретиться. Если `from` и `to` равны, возвращается это значение.

Если параметры выходят за пределы диапазона, перепутаны местами или не являются числами, возникает исключение Lua; этот экземпляр уничтожается, а шум в этот раз не отправляется.

**Пример**

```lua
local noise = require("xray.finalmask.noise")

function HandleNoise(plan, address)
    for i = 1, noise.RandomBetween(2, 5) do
        plan:Add(noise.Random(noise.RandomBetween(40, 90)), noise.RandomBetween(10, 20))
    end
end
```

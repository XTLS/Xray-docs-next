# Hook шума

Когда нужно отправить шум на некоторый адрес, ядро вызывает глобальную функцию `HandleNoise` из `script` в [маскировке noise](../../../config/transports/finalmask.md#noise). Настройка и полные примеры приведены в [руководстве по скриптам шума](../guide/noise.md).

## Указатель API

| Категория | Член API                                 | Описание                            |
| --------- | ---------------------------------------- | ----------------------------------- |
| Hook      | [`HandleNoise(...)`](#handlenoise)       | Генерация пакетов шума              |
| Метод     | [`plan:Add(...)`](#plan-add)             | Передача одного пакета шума         |
| Метод     | [`plan:AddRandom(...)`](#plan-addrandom) | Передача пакета из случайных байтов |

## Интерфейс Hook

### HandleNoise(...)

```lua
function HandleNoise(plan, address)
    return err
end
```

Генерирует пакеты шума для текущей отправки. Пакеты по одному передаются через [`plan:Add`](#plan-add), а возвращаемое значение используется только для сообщения об ошибке.

#### Параметры

Ядро всегда передаёт эти параметры; они не равны `nil`.

| Параметр  | Тип        | Описание                                                          |
| --------- | ---------- | ----------------------------------------------------------------- |
| `plan`    | `userdata` | План отправки для этого вызова; пакеты передаются `plan:Add`      |
| `address` | `string`   | Адрес назначения текущей отправки, вида `192.0.2.1:443`, непустой |

Для одного и того же адреса вызов происходит только один раз, при первой отправке данных; если настроен `reset`, по истечении этого времени вызов происходит снова.

#### Возвращаемые значения

| Значение | Тип                                                  | Описание                                |
| -------- | ---------------------------------------------------- | --------------------------------------- |
| `err`    | [`error`](./data-types.md#error), `string` или `nil` | Только `nil` означает отсутствие ошибки |

Если сообщать об ошибке не нужно, возвращаемое значение не требуется. Ядро читает только первое возвращаемое значение, остальные игнорируются.

#### Поведение

Шум — это маскировка по мере возможности, и его сбой не влияет на обычную передачу данных: при ошибке в скрипте или исключении выполнения ядро записывает одно сообщение уровня `warning`, в этот раз шум не отправляется, а затем реальный пакет данных отправляется как обычно. Это соответствует поведению при сбое отправки статического шума.

| Результат скрипта                           | Действие ядра                                                                  |
| ------------------------------------------- | ------------------------------------------------------------------------------ |
| `plan:Add` вызывался, ошибок нет            | Эти пакеты отправляются в порядке передачи, затем реальные данные              |
| `plan:Add` не вызывался, ошибок нет         | Шум не отправляется, реальные данные отправляются сразу                        |
| Возвращена ошибка или исключение выполнения | Переданные в этот раз пакеты отбрасываются, реальные данные отправляются сразу |

Hook выполняется синхронно перед отправкой реального пакета данных, поэтому он должен быть как можно легковеснее, а длительную инициализацию следует размещать на верхнем уровне скрипта. Тайм-аут выполнения каждого вызова составляет **1 секунду**, а тайм-аут инициализации экземпляра — **120 секунд**; подробнее — в разделе [Жизненный цикл пула](../guide/lifecycle.md#жизненныи-цикл-пула).

#### Пример

```lua
local noise = require("xray.finalmask.noise")

function HandleNoise(plan, address)
    plan:Add("\22\3\1")
    plan:Add(noise.Random(64), noise.RandomBetween(10, 20))
end
```

## Методы

### plan:Add

```lua
plan:Add(packet)
plan:Add(packet, delay)
```

Передаёт один пакет шума в план текущего вызова. Можно вызывать несколько раз; ядро отправляет пакеты в порядке вызовов, а реальный пакет данных отправляет только после отправки всех из них.

#### Параметры

| Параметр | Тип                | Описание / Требования                                                                                                 |
| -------- | ------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `packet` | `string`           | Обязателен; содержимое пакета, допускается пустая строка                                                              |
| `delay`  | `number` или `nil` | Необязателен; задержка после отправки этого пакета в миллисекундах, должна быть целым числом в диапазоне `0 .. 65535` |

Содержимое пакета — это байтовая строка, которая может содержать любые байты, в том числе `\0`; её длина должна помещаться в одну дейтаграмму.

#### Возвращаемые значения

Нет возвращаемых значений.

#### Поведение

План принимает пакеты только во время выполнения этого вызова Hook. Если сохранить `plan` в глобальной переменной и обратиться к нему вне Hook, возникает исключение Lua.

За один вызов можно передать не более **64** пакетов, а их суммарная длина не должна превышать **65535** байт. Эти два предела не дают скрипту, которым поделились вместе с конфигурацией, занять всю память; при превышении возникает исключение Lua.

Если тип или диапазон параметров недопустим, также возникает исключение Lua; этот экземпляр уничтожается, все переданные в этот раз пакеты отбрасываются, а шум не отправляется.

### plan:AddRandom

```lua
plan:AddRandom(size)
plan:AddRandom(size, delay)
```

Передаёт один пакет шума, состоящий из случайных байтов. Это то же самое, что `plan:Add(noise.Random(size))`, но случайные данные не проходят через Lua, что экономит одну передачу строки.

#### Параметры

| Параметр | Тип                | Описание / Требования                                                       |
| -------- | ------------------ | --------------------------------------------------------------------------- |
| `size`   | `number`           | Обязателен; число байтов, должно быть целым числом в диапазоне `0 .. 65535` |
| `delay`  | `number` или `nil` | Необязателен; то же, что `delay` у `plan:Add`                               |

#### Возвращаемые значения

Нет возвращаемых значений.

#### Поведение

Ограничения и исключения те же, что у `plan:Add`, а источник случайных данных тот же, что у [`noise.Random`](./module-noise.md#noise-random).

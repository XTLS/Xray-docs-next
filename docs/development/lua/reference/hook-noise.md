# 噪声 Hook

核心在需要向某个地址发送噪声时调用 [noise 伪装](../../../config/transports/finalmask.md#noise)的 `script` 中的全局函数 `HandleNoise`。配置接入和完整示例见[噪声脚本指南](../guide/noise.md)。

## API 索引

| 分类 | 成员                                     | 说明                 |
| ---- | ---------------------------------------- | -------------------- |
| Hook | [`HandleNoise(...)`](#handlenoise)       | 生成噪声包           |
| 方法 | [`plan:Add(...)`](#plan-add)             | 提交一个噪声包       |
| 方法 | [`plan:AddRandom(...)`](#plan-addrandom) | 提交一个随机字节的包 |

## Hook 接口

### HandleNoise(...)

```lua
function HandleNoise(plan, address)
    return err
end
```

生成本次要发送的噪声包。包通过 [`plan:Add`](#plan-add) 逐个提交，返回值只用于报告错误。

#### 参数

核心始终传入这些参数，不为 `nil`。

| 参数      | 类型       | 说明                                           |
| --------- | ---------- | ---------------------------------------------- |
| `plan`    | `userdata` | 本次的发送计划，用 `plan:Add` 提交包           |
| `address` | `string`   | 本次发送的目标地址，形如 `192.0.2.1:443`，非空 |

同一地址只在首次发送数据时调用一次；配置了 `reset` 时，经过该时间后会再次调用。

#### 返回值

| 返回值 | 类型                                                | 说明                |
| ------ | --------------------------------------------------- | ------------------- |
| `err`  | [`error`](./data-types.md#error)、`string` 或 `nil` | 仅 `nil` 表示无错误 |

不需要报错时无需返回值。核心只读取第一个返回值，其余会被忽略。

#### 行为约定

噪声是尽力而为的伪装，失败不影响正常通信：脚本报错或执行异常时，核心记录一条 `warning` 日志，本次不发送噪声，随后照常发送真实数据包。这与静态噪声发送失败时的行为一致。

| 脚本结果                     | 核心处理                           |
| ---------------------------- | ---------------------------------- |
| 调用过 `plan:Add` 且未报错   | 按提交顺序发送这些包，再发真实数据 |
| 没有调用 `plan:Add` 且未报错 | 不发噪声，直接发真实数据           |
| 返回错误或执行异常           | 丢弃本次已提交的包，直接发真实数据 |

Hook 在真实数据包发送前同步执行，因此应尽量轻量，耗时较长的初始化请放在脚本顶层。每次调用的执行超时为 **1 秒**，实例初始化超时为 **120 秒**，详见[池化生命周期](../guide/lifecycle.md#池化生命周期)。

#### 示例

```lua
local noise = require("xray.finalmask.noise")

function HandleNoise(plan, address)
    plan:Add("\22\3\1")
    plan:Add(noise.Random(64), noise.RandomBetween(10, 20))
end
```

## 方法

### plan:Add

```lua
plan:Add(packet)
plan:Add(packet, delay)
```

向本次计划提交一个噪声包。可以多次调用，核心按调用顺序发送，全部发完后再发送真实数据包。

#### 参数

| 参数     | 类型              | 说明 / 要求                                                      |
| -------- | ----------------- | ---------------------------------------------------------------- |
| `packet` | `string`          | 必填，包内容，允许空字符串                                       |
| `delay`  | `number` 或 `nil` | 可选，发送该包后的延迟，单位毫秒，须为 `0 .. 65535` 范围内的整数 |

包内容是字节串，可以包含 `\0` 等任意字节，长度须能放进一个数据报。

#### 返回值

无返回值。

#### 行为约定

计划只在本次 Hook 执行期间收包。把 `plan` 存到脚本的全局变量里，之后在 Hook 之外使用会抛出 Lua 异常。

每次调用最多提交 **64** 个包，所有包的总长度最多 **65535** 字节。这两个上限让随配置分享的脚本无法占满内存，超出时抛出 Lua 异常。

参数类型或范围不合法时同样抛出 Lua 异常，该实例会被销毁，本次已提交的包全部丢弃，不发送噪声。

### plan:AddRandom

```lua
plan:AddRandom(size)
plan:AddRandom(size, delay)
```

提交一个内容为随机字节的噪声包，等价于 `plan:Add(noise.Random(size))`，但随机数据不经过 Lua，少一次字符串往返。

#### 参数

| 参数    | 类型              | 说明 / 要求                                  |
| ------- | ----------------- | -------------------------------------------- |
| `size`  | `number`          | 必填，字节数，须为 `0 .. 65535` 范围内的整数 |
| `delay` | `number` 或 `nil` | 可选，与 `plan:Add` 的 `delay` 相同          |

#### 返回值

无返回值。

#### 行为约定

上限、异常行为与 `plan:Add` 相同，随机源与 [`noise.Random`](./module-noise.md#noise-random) 相同。
